# AgiSort
A novel average case O(n) sorting algorithm.

## Python Installation
```
pip install agisort
```

### C Installation
```
git clone git@github.com:AgiGames/AgiSort.git
```
To compile file ```main.c``` that uses agisort:
```
gcc .\main.c .\c_impl\agisort.c .\c_impl\heap.c -I.\c_impl\ -o main
```
